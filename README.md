# GPA Calculator 🎓

A simple and interactive GPA Calculator designed to help students calculate and track their academic performance.

## ✨ Features

- Calculate GPA using 4.0 or 5.0 grading scales.
- Add and remove courses.
- Enter course names, credit hours, and grades.
- Automatically calculate GPA.
- Display total credit hours and number of courses.
- English and Arabic language support.
- Light and dark themes.
- Automatically save data using browser Local Storage.
- Responsive and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start calculating your GPA!

No installation or backend server is required.

## 💾 Data Storage

The application uses browser Local Storage to save course information locally. Data is stored in the user's browser and is not synchronized across different devices.
